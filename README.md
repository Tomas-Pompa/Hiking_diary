# Náš turistický deník

Tento repozitář (a příslušná webová stránka) obsahuje záznamy z našich výletů. Jednotlivé položky jsou rozděleny do skupin:

* Hut
* Peak
* Ferrata
* Camp

Ke každému záznamu jsou uvedeny souřadnice, datum návštěvy, krátký a případně i dlouhý popis a někdy i fotka. Fotky jsou uloženy v samostatné složce podle typu záznamu. 

> Dlouhý popis nám slouží k uchování nejdůležitějších informací o daném místě (náročnost ferraty, exponovanost, pitná voda a zásuvky na chatě, kvalita a typ jídla a snídaně apod.).
